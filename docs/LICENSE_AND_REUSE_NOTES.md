# License and Reuse Notes

## Recommended license for original AraVISTA materials
CC BY 4.0 for:
- original annotations;
- construction-derived labels;
- benchmark metadata created by the authors;
- schemas and documentation;
- original controlled reformulations created by the authors, where no third-party rights attach.

## Third-party source material
Official webpages and dated institutional records may be publicly accessible while still being
copyrighted. Public accessibility is not equivalent to public-domain status.

Before public release, review every evidence field that contains verbatim or near-verbatim source
text. If redistribution rights are unclear, the safer release format is:
- evidence ID;
- source URL;
- source organization;
- source title;
- source publication/update date;
- retrieval/source-chain metadata;
- checksum/hash;
- annotation and label fields;
- a short factual description or author-created transformation where appropriate;
- no full third-party passage text.

The repository license should explicitly state that third-party source content, if any, remains
subject to the original rights holder's terms and is excluded from the dataset license unless
permission has been obtained.
